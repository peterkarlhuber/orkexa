# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone who participates in issues, pull requests, reviews
and other project spaces is expected to follow it.

In short: be respectful and constructive, welcome people regardless of background or
identity, accept that others may disagree, and do not harass, insult or publish
anyone's private information.

## Reporting

Report unacceptable behavior to the repository owner (GitHub user `peterkarlhuber`)
privately, for example through GitHub's private vulnerability reporting form if it is
enabled, or by opening an issue that asks for a private contact without describing the
incident. Reports are handled confidentially. The repository owner decides on
consequences as described in the Contributor Covenant's enforcement guidelines.
