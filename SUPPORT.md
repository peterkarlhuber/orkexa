# Support

Orkexa is an open-source project maintained in spare time. There is no commercial
support and no guaranteed response time.

* **Questions and problems:** first check the [documentation](docs/index.md),
  especially [Troubleshooting and FAQ](docs/troubleshooting.md). If that does not help,
  open an issue with the "Bug report" or "Feature request" template.
* **Security issues:** never in public issues; see [SECURITY.md](SECURITY.md).
* **Provider accounts, billing, quotas and model behavior:** contact the provider
  (Anthropic, OpenAI, Google) directly; Orkexa cannot change them.

When you report a problem, include the Orkexa version or commit, the Python version,
the provider SDK versions (`pip show anthropic openai google-genai`), a minimal script,
and the full exception. Remove API keys and personal data first.
